sillyname-tamil

புணர்ச்சி — silly Tamil names that actually join

Tamil doesn't build names by setting two words side by side. The modifier takes an attributive form and the seam between the words changes: கரு + குயில் becomes கருங்குயில், growing a ங் that was in neither word. This generator applies those rules, so press the button and watch the seam.

The five junction classes

ClassRuleExample
nasal A homorganic nasal appears before க / ச / த / ப கரு + குயில் → கருங்குயில்
double The hard consonant doubles across the seam நீல + தாமரை → நீலத்தாமரை
ran A ன்-final stem turns its ன் into ற் பொன் + கிளி → பொற்கிளி
plain Nothing changes at the seam வெண் + மயில் → வெண்மயில்
phrase A relative participle stays its own word பறக்கும் + பூனை → பறக்கும் பூனை

These classes are assigned by hand per word, not derived from spelling, because Tamil sandhi is lexical. ஜொலிக்கும் ends in ம் but is a participle, so stripping it yields nonsense; and பொன் + சிலை is பொற்சிலை while மின் + சாரம் stays மின்சாரம்.

Install

npm i sillyname-tamil const generateName = require('sillyname-tamil'); generateName(); // 'கருங்குயில்' generateName({ format: 'latin' }); // 'karunguyil'
